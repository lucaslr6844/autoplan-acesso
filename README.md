# Autoplan — tela de acesso

Frontend estático hospedado pelo GitHub Pages. Este repositório contém apenas a apresentação da tela: não inclui relação de processos, senhas, chaves ou documentos privados.

O acesso por usuário e senha ainda não está ativado. O formulário permanece bloqueado e não transmite credenciais. O GitHub Pages não executa o servidor Node.js da aplicação; a ativação depende de um serviço de autenticação e de uma API protegida configurados separadamente.

Publicação: branch `main`, pasta `/ (root)`.
